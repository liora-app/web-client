# ТЕХНІЧНЕ ЗАВДАННЯ: ІММЕРСИВНИЙ 3D-ПРОСТІР "LIORA — SPATIAL SANCTUARY"

Ти — Senior Creative Technologist та WebGL/Three.js Архітектор.
Твоє завдання — розробити повний, готовий до продакшену односторінковий вебзастосунок для платформи психологічної саморефлексії **Liora**. 

Замість плаского лендингу реалізуй концепцію **"Spatial Sanctuary" (Затишний 3D-острівець)**: прокручування колеса миші (скрол) плавно переміщує 3D-камеру за вигнутою траєкторією через 5 ключових локацій острівця, а на фінальному етапі безшовно садить користувача в крісло навпроти 3D-компаньйона для живої текстової або голосової розмови.

## 1. АРХІТЕКТУРА, СТЕК ТА ОБМЕЖЕННЯ (БЕЗ ЗАЙВИХ АБСТРАКЦІЙ)

1. **Технологічний стек:**
   - **3D:** `Three.js` (або `React Three Fiber` + `@react-three/drei`, якщо проєкт на React).
   - **Анімація та скрол:** `GSAP` (`ScrollTrigger`) + `Lenis` (для інерційного згладжування скролу).
   - **Голос та аудіо:** Нативні браузерні `Web Speech API` (`SpeechRecognition` / `webkitSpeechRecognition`) та `Web Audio API` (`AnalyserNode`).
   - **Заборонено:** Не підключай важкі фізичні рушії (`Cannon.js`, `Rapier`, `Ammo.js`) чи сторонні бібліотеки для дрібних UI-ефектів — уся динаміка вирішується чистими математичними функціями (`Math.sin`, `Math.cos`, `lerp`, `CatmullRomCurve3`) та нативним CSS.

2. **DOM-структура та Шари:**
   - **Шар 1 (`#webgl-container`):** `position: fixed; inset: 0; width: 100vw; height: 100vh; z-index: 1; pointer-events: none;` (pointer-events вмикаються локально або через `Raycaster` на рівні `window` для інтерактивних 3D-предметів).
   - **Шар 2 (`#scroll-Wrapper`):** Семантичний HTML-контейнер (`position: relative; z-index: 2;`), що складається з 5 секцій (`<section class="stage" data-stage="0..4">`), кожна висотою `100vh` (загальна висота скролу `500vh`). Інтерактивні картки та кнопки мають `pointer-events: auto;`.
   - **Приховування нативного скролбара браузера:**
     ```css
     html, body {
       scrollbar-width: none; /* Firefox */
       -ms-overflow-style: none; /* IE/Edge */
       overscroll-behavior: none;
     }
     html::-webkit-scrollbar {
       display: none; /* Chrome, Safari, Opera */
     }
     ```

## 2. КОЛІРНА ПАЛІТРА, СВІТЛО ТА МАТЕРІАЛИ (НЕЙРОЕСТЕТИКА СПОКОЮ)

Жодних глянцевих, косметичних чи неонових відтінків. Усі поверхні імітують сухі, тактильні природні матеріали (глина, повсть, небілений льон, тепла деревина, матова кераміка).

### 2.1. Кольорова схема (HEX / RGBA)
- **Фон 3D-сцени та туман:** Глибокий хвойно-лісовий `#11221A`.
- **Фон HTML-карток (Glassmorphism):** `rgba(20, 38, 29, 0.76)` з розмиттям `backdrop-filter: blur(14px)` та тонкою рамкою `1px solid rgba(235, 231, 224, 0.12)`.
- **Основний текст (Заголовки):** Теплий небілений льон `#EBE7E0`.
- **Вторинний текст (Описи, підписи):** Приглушений шавлієво-сірий `#A3B2A8`.
- **Акцентні кнопки (Primary CTA):** Фон `#EAE3D2`, текст `#14241B`, при ховері м'яке бурштинове світіння `box-shadow: 0 0 24px rgba(245, 208, 138, 0.35)`.
- **Світлове ядро та частинки:** Теплий бурштин `#FFB84D` у центрі з переходом у м'яке золото `#F5D08A` на краях.

### 2.2. Налаштування 3D-матеріалів (PBR)
- **Керамічний лотос (`MeshStandardMaterial`):**
  - Базовий колір пелюсток: теплий кремовий `#F2ECE1` біля основи з плавним вертексним або текстурним градієнтом у приглушену теракоту `#9E3B33` на кінчиках пелюсток.
  - Параметри: `roughness: 0.88`, `metalness: 0.0`, `flatShading: false`.
  - Обов'язково: пелюстки мають геометричну товщину (`extrude` / `bevel`), увімкнені `castShadow = true` та `receiveShadow = true` для чіткого самозатінення (self-shadowing), щоб краї пелюсток не зливалися в білу пляму.
- **Острівець (Глина та повстяний мох):**
  - Верхній шар моху: приглушений шавлієвий `#2D4A3A`, `roughness: 0.96`.
  - Схили острівця та камені: матова скульптурна глина `#3B362E`, `roughness: 0.92`.
- **Деревина (Колода, столик, скринька, крісло, стовбур дерева):**
  - Теплий матовий горіх `#4A3525`, `roughness: 0.85`, `metalness: 0.05`.
- **Папір (Сторінки щоденника та ліхтарики на дереві):**
  - Колір `#F4EFE6`, `roughness: 0.9`. Для ліхтариків додай `emissive: new THREE.Color('#FFB84D')` з динамічним `emissiveIntensity`.

### 2.3. Система освітлення та Глибина
1. **Туман:** `scene.fog = new THREE.FogExp2('#11221A', 0.032)` — розчиняє далекі межі та створює глибоку повітряну перспективу.
2. **AmbientLight:** Колір `#243B2E`, `intensity: 0.55` (м'яке базове заповнення без пересвіту).
3. **DirectionalLight (Сутінкове світло зверху-зліва):** Колір `#D4E2D9`, `intensity: 0.75`, позиція `[-6, 10, 6]`, `castShadow = true`, `shadow.mapSize.set(2048, 2048)`, `shadow.bias = -0.0005`, `shadow.radius = 4`.
4. **Головний PointLight (Серцевина лотоса):** Колір `#FFB84D`, базова `intensity: 2.2`, `distance: 11`, `decay: 2.0`, позиція `[0, 0.45, 0]`, `castShadow = true`.
5. **Контактні тіні (Ambient Occlusion):** Під кожним предметом на поверхні острівця додай м'які темні контактні тіні (через `ContactShadows` або запечені напівпрозорі плашки з радіальним градієнтом `#09130E`), щоб об'єкти не виглядали «підвішеними в повітрі».

## 3. КОМПОЗИЦІЯ ОСТРІВЦЯ ТА КООРДИНАТИ ОБ'ЄКТІВ

Центр острівця знаходиться в точці `[0, 0, 0]`. Вся група острівця має повільну фонову левітацію в `requestAnimationFrame`: `islandGroup.position.y = Math.sin(elapsedTime * 0.6) * 0.06`.

1. **Основа острівця (`IslandBase`):** Позиція `[0, -0.6, 0]`, радіус `4.5`, висота `1.2`, асиметрична форма зі згладженими краями.
2. **Сяючий лотос (`LotusCenter`):** Позиція `[0, 0.15, 0]`. Складається з 3 ярусів окремих вигнутих пелюсток (по 8 пелюсток у ярусі). Усередині — ідеально кругла сфера світла (`SphereGeometry(0.26, 32, 32)`).
3. **3D-Компаньйон (`CompanionCharacter`):** Позиція `[0.2, 0.15, -1.35]`, сидить на дерев'яній колоді обличчям до лотоса і глядача.
   - *Дизайн:* Затишний крафтовий персонаж у стилі stop-motion / *It Takes Two*: матове глиняне тіло з м'якими округлими пропорціями, добрі темні очі-ґудзики, об'ємний в'язаний светр із дерев'яним ґудзиком, на маківці — маленький сяючий бутон лотоса.
   - *Технічна реалізація:* Передбач завантаження `.glb` моделі через `GLTFLoader` з обов'язковим процедурним фолбеком (збірна стилізована фігурка з окремими групами `headGroup`, `torsoGroup`, `rightArmGroup`, `leftArmGroup`, `eyesMesh`), щоб сцена працювала одразу без зовнішніх асетів.
4. **Низький столик із розкритим щоденником (`JournalStation`):** Позиція `[-1.55, 0.22, 0.75]`, повернутий на `0.45 рад` до центру. На столику лежить розкритий паперовий щоденник із рухомою сторінкою (`pagePivot`), закріпленою по центральному корінцю.
5. **Дерев'яна скринька приватності (`PrivacyChest`):** Позиція `[-1.05, 0.08, 1.55]`. Складається з корпусу, рухомої кришки (`lidPivot`, кут відкриття `0..Math.PI / 3`), навісного матового замка та ключа (`keyPivot`).
6. **Розлоге дерево з 3 ліхтариками (`LanternTree`):** Стовбур у точці `[1.85, 0.0, -0.85]`, гілки нависають над острівцем на висоті `Y: 2.1 – 2.7`. На гілках на тонких нитках висять 3 паперові ліхтарики-бутони з власними точковими світильниками малої потужності:
   - Ліхтарик 1: `[0.85, 2.25, -0.35]`
   - Ліхтарик 2: `[1.35, 2.45, -0.15]`
   - Ліхтарик 3: `[1.85, 2.15, -0.45]`
7. **Вільне крісло для користувача (`UserChair`):** Позиція `[0.0, 0.12, 1.85]`, розвернуте точно на компаньйона та лотос.

## 4. МАТЕМАТИКА РУХУ КАМЕРИ (SCROLL-DRIVEN CAMERA RIG)

Користувач керує переміщенням виключно колесом миші (або свайпом). Камера рухається по двох синхронізованих сплайнах `THREE.CatmullRomCurve3`: один для позиції камери (`cameraCurve`), другий для точки фокусу (`targetCurve`).

### 4.1. Точні координати 5 Етапів (Waypoints)

| Етап | Прогрес скролу (`p`) | Позиція камери (`cameraCurve`) | Точка погляду (`targetCurve`) | Опис плану |
| :--- | :--- | :--- | :--- | :--- |
| **01. Hero** | `0.00` | `[-2.1, 2.0, 5.6]` | `[0.5, 0.45, 0.0]` | Загальний план: острівець трохи праворуч, зліва простір під головний заголовок. |
| **02. Щоденник** | `0.25` | `[-2.25, 1.1, 1.95]` | `[-1.55, 0.3, 0.75]` | Крупний наїзд на розкритий паперовий щоденник на столику. |
| **03. Скринька** | `0.50` | `[-1.75, 0.65, 2.65]` | `[-1.05, 0.18, 1.55]` | Низький камерний фокус на дерев'яній скриньці з замком. |
| **04. Ліхтарики** | `0.75` | `[0.25, 1.75, 2.1]` | `[1.35, 2.3, -0.3]` | Погляд знизу-вгору крізь гілки дерева на 3 сяючі ліхтарики. |
| **05. Живий чат** | `1.00` | `[0.0, 1.05, 1.5]` | `[0.15, 0.72, -1.25]` | Посадка в крісло навпроти компаньйона на рівні його очей. |

### 4.2. Логіка GSAP ScrollTrigger + Lenis + Mouse Parallax
- Ініціалізуй `Lenis` з параметрами `lerp: 0.08`, `smoothWheel: true`.
- Налаштуй `ScrollTrigger` на контейнер `#scroll-wrapper`:
  ```javascript
  ScrollTrigger.create({
    trigger: '#scroll-wrapper',
    start: 'top top',
    end: 'bottom bottom',
    scrub: 1.2,
    snap: {
      snapTo: [0, 0.25, 0.5, 0.75, 1],
      duration: { min: 0.4, max: 0.85 },
      delay: 0.05,
      ease: 'power2.inOut'
    },
    onUpdate: (self) => {
      scrollProgress = self.progress;
    }
  });
  ```
- У кожному кадрі (`requestAnimationFrame`):
  1. Отримуй базову точку ` cameraCurve.getPointAt(scrollProgress)` та `targetCurve.getPointAt(scrollProgress)`.
  2. Додавай м'який паралакс від курсора миші (`pointer.x`, `pointer.y` у діапазоні `[-1, 1]`):
     - Зміщення `parallaxX = THREE.MathUtils.lerp(parallaxX, pointer.x * 0.2, 0.05)`
     - Зміщення `parallaxY = THREE.MathUtils.lerp(parallaxY, pointer.y * 0.12, 0.05)`
     - На Етапі 5 (`scrollProgress > 0.85`) зменшуй множник паралакса на 70%, щоб під час розмови в кріслі камера була максимально спокійною.

## 5. ПОВЕДІНКА СВІТЛОВОГО ЯДРА ТА ЧАСТИНОК (БЕЗ ДЕФОРМАЦІЇ ФОРМИ)

1. **Заборона розтягування сфери:**
   - Світлове ядро в центрі лотоса ЗАВЖДИ зберігає ідеальну сферичну геометрію (`scale.x === scale.y === scale.z`). Категорично заборонено розтягувати або сплющувати сферу залежно від швидкості скролу.

2. **Біоритм дихання (4 секунди вдих / 6 секунд видих):**
   - Повний цикл дихання становить `10.0` секунд (`cycle = (elapsedTime % 10) / 10`):
     - Якщо `cycle < 0.4` (фаза вдиху, 4 сек): плавний перехід `breathPhase = 0.5 - 0.5 * Math.cos((cycle / 0.4) * Math.PI)`.
     - Якщо `cycle >= 0.4` (фаза видиху, 6 сек): плавний спад `breathPhase = 0.5 + 0.5 * Math.cos(((cycle - 0.4) / 0.6) * Math.PI)`.
   - Застосовуй `breathPhase` до масштабу ядра (`scale = 1.0 + breathPhase * 0.16`), радіуса зовнішнього ореолу та яскравості `PointLight` (`intensity = 1.8 + breathPhase * 0.9`).

3. **Інтерактивний шлейф частинок від скролу (`ScrollVelocityParticles`):**
   - Створи систему з `65` частинок (`THREE.Points` із кастомним шейдером або м'якою радіальною текстурою, `blending: THREE.AdditiveBlending`, `depthWrite: false`, `transparent: true`).
   - Зчитуй поточну швидкість скролу з Lenis: `velocityFactor = Math.min(Math.abs(lenis.velocity) * 0.12, 1.0)`.
   - **У стані спокою (`velocityFactor < 0.05`):** частинки повільно ширяють навколо острівця з ледь помітною прозорістю (`opacity: 0.25`) і швидкістю підйому `y += 0.002`.
   - **Під час активного скролу:** частинки прискорюються вздовж траєкторії руху, їхня яскравість зростає до `0.9`, формуючи м'який золотистий шлейф у повітрі. Після зупинки скролу шлейф плавно тане за `1.2` секунди.

## 6. ДЕТАЛЬНИЙ СЦЕНАРІЙ UI ТА 3D-ІНТЕРАКТИВУ ПО ЕТАПАХ

### Постійний Верхній Хедер (`position: fixed; top: 0; z-index: 10`)
- **Ліворуч:** Логотип `Liora` + іконка маленької органічної сфери. Клік повертає скрол на початок (`lenis.scrollTo(0)`).
- **По центру:** Навігаційні посилання:
  - `Як це працює` -> плавний скрол до Етапу 2 (`25%`).
  - `Приватність` -> плавний скрол до Етапу 3 (`50%`).
  - `Запитання` -> плавний скрол до Етапу 4 (`75%`).
- **Праворуч:**
  - Кнопка `Якщо важко` — відкриває доступне модальне вікно (`role="dialog"`, `aria-modal="true"`) з контактами екстреної психологічної та медичної допомоги (`112` або `103`).
  - Інтерактивний віджет звукової хвилі (SVG-лінія, яка плавно коливається при увімкненому фоновому ембієнті).

### ЕТАП 1 (`scroll: 0.00`) — Hero «Почуйте себе»
- **HTML-контент (ліва частина екрана):**
  - Надзаголовок: `• ВАШ ОСОБИСТИЙ ПРОСТІР`
  - Головний заголовок (`h1`): `Почуйте себе.` (слово *себе* виділене курсивом *serif* шрифтом у теплому пісочному відтінку).
  - Опис: `Коли ззовні забагато шуму. Місце для ваших думок, почуттів і пауз.`
  - Підпис: `AI-помічник для саморефлексії`
  - Кнопка CTA: `Почати розмову ↗` (клік запускає плавний проліт `lenis.scrollTo('bottom', { duration: 2.2 })` одразу в крісло до Етапу 5).
  - Нижній індикатор: `↓ ГОРТАЙТЕ ПОВІЛЬНО` та лічильник секції `01 / 05`.
- **3D-поведінка:** Компаньйон сидить біля лотоса, повільно дихає, раз на 3–5 секунд кліпає очима і плавно повертає голову за курсором миші (`headGroup.rotation.y = lerp(...)`).

### ЕТАП 2 (`scroll: 0.25`) — Наїзд на щоденник: «З чого почнемо?»
- **HTML-контент (спливає біля столика зі щоденником):**
  - Надзаголовок: `02 / ВАШ НАПРЯМОК`
  - Заголовок (`h2`): `З чого почнемо?`
  - **Інтерактивні вкладки (3 картки напрямків):**

    3. `03 / ТУРБОТА` — **Будьте на своєму боці.** *Ваші почуття мають значення.*
  - **Блок процесу під вкладками («Маленька розмова. Трохи більше ясності.»):**
    - `01 Поділіться своїм` — Напишіть те, що зараз важливо. Можна почати з «Не знаю, з чого почати».

### ЕТАП 3 (`scroll: 0.50`) — Фокус на скриньці: «Ви вирішуєте, чим ділитися»

## 7. ВАЛІДАЦІЯ ДАНИХ, ОБРОБКА ПОМИЛОК, БЕЗПЕКА ТА ДОСТУПНІСТЬ (ОБОВ'ЯЗКОВО)

1. **Валідація та Безпека (XSS Protection):**
   - Очищуй будь-який користувацький ввід у чаті через `.trim()`, обмежуй довжину до `500` символів.
   - Виводь повідомлення користувача виключно через `textContent` (категорично заборонено вставляти сирий рядок у `innerHTML`).

2. **Обробка помилок (Resilience & Fallbacks):**
   - **WebGL Context:** Додай перевірку доступності WebGL та слухачі `canvas.addEventListener('webglcontextlost', (e) => { e.preventDefault(); ... })`. Якщо WebGL недоступний або впав, показуй чистий стилізований CSS-градієнтний фон із повідомленням без падіння скриптів.
   - **Голосове введення (`SpeechRecognition` / `getUserMedia`):** Перевіряй наявність `window.SpeechRecognition || window.webkitSpeechRecognition`. Обробляй помилки відмови в доступі до мікрофона (`not-allowed`, `no-speech`, `network`) через акуратне тост-повідомлення українською мовою (*«Мікрофон недоступний або доступ заборонено в налаштуваннях браузера. Ви можете продовжити розмову текстом»*), повертаючи кнопку мікрофона у безпечний вимкнений стан.

3. **Доступність (Accessibility / A11y):**
   - Підтримка `prefers-reduced-motion: reduce`: якщо у користувача в системі увімкнено зменшення руху, вимикай постійне погойдування острівця, паралакс миші та зменшуй кількість частинок, залишаючи лише плавні переходи між секціями.
   - Повна підтримка клавіатури: перехід між інтерактивними елементами через `Tab` із видимим `focus-visible` контуром (`2px solid #F5D08A`), перемикання етапів стрілками `ArrowDown` / `ArrowUp` або `PageDown` / `PageUp`, закриття модального вікна допомоги клавішею `Escape`.
